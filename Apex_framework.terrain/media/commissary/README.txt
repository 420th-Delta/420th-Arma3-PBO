Cosmetic Commissary skin deployment

Place each completed or approved .paa file in this directory.

The game accepts both the original randomized upload filename and the normalized
filename supplied by the Cosmetic Commissary admin download, such as:

    my_skin_a1b2c3d4.paa
    my_skin.paa

For skins with multiple texture files, keep the numbered texture filenames from
the dashboard. The number determines the vehicle hidden-selection index:

    my_skin_texture_1_a1b2c3d4.paa -> hiddenSelection 0
    my_skin_texture_2_e5f6a7b8.paa -> hiddenSelection 1
